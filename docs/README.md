## Documentation structure:
- `media/*` - Holds pictures and screenshots used inside the documentation.
- `flowcharts/*` - System and user interaction flow chart in `.md` and `.svg`.
- `ui/*` - Contains UI mockup screenshots sketched in Affinity.
